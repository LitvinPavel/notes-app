# Notes App (Nuxt 3 SPA)

SPA-приложение для управления заметками и списками задач с кастомным движком Undo/Redo, версионированным хранилищем и поддержкой работы в Docker.

**Демо (GitHub Pages)**: [https://litvinpavel.github.io/notes-app/](https://litvinpavel.github.io/notes-app/)

## Стек технологий

- **Фреймворк**: Nuxt 3 (SPA-режим, Vue 3 Composition API, `<script setup lang="ts">`)
- **Язык**: TypeScript (`strict: true`)
- **Стейт-менеджер**: Pinia
- **Стилизация**: Модульный SCSS/SASS (без сторонних UI-библиотек)
- **Тестирование**: Vitest
- **Контейнеризация**: Docker, Docker Compose

---

## Быстрый старт

### Требования
- Node.js >= 20
- pnpm >= 9 (или npm / yarn)

### Установка зависимостей
```bash
pnpm install
```

### Запуск в режиме разработки
```bash
pnpm dev
```
Приложение будет доступно по адресу [http://localhost:3000](http://localhost:3000).

### Сборка и предпросмотр
```bash
# Сборка production-бандла
pnpm build

# Запуск собранного приложения
pnpm preview
```

## Тестирование и линтинг

```bash
# Запуск Unit-тестов (Vitest)
pnpm test

# Запуск тестов в watch-режиме
pnpm test:watch

# Проверка типов TypeScript
pnpm typecheck
```

## Запуск в Docker

Для локального развертывания с помощью Docker Compose выполните:

```bash
docker compose up --build
```

Приложение будет собрано и запущено в изолированном контейнере на порту `3000`:
[http://localhost:3000](http://localhost:3000).

Остановка контейнера:
```bash
docker compose down
```

## Горячие клавиши (на странице редактирования)

| Сочетание клавиш | Действие |
| ---------------- | -------- |
| `Ctrl + Z` / `Cmd + Z` | Отменить последнее действие (Undo) |
| `Shift + Ctrl + Z` / `Shift + Cmd + Z` / `Ctrl + Y` | Повторить отменённое действие (Redo) |
| `Enter` (в поле задачи) | Добавить новую задачу и сфокусироваться на ней |
| `Escape` (в модальном окне) | Закрыть модальное окно |
| `Tab` / `Shift + Tab` | Циклическая навигация внутри модального окна (Focus Trap) |

## Архитектурные особенности

- **Движок Undo/Redo**: паттерн «Команда» (Command / Inverted Delta) с лимитом 50 шагов. Хранятся только атомарные изменения, а не полные снимки состояния; ввод текста группируется по сессиям (дебаунс 600 мс).
- **Версионирование схемы**: данные в `localStorage` хранятся в конверте с версией схемы (`version: 1`). Предусмотрена защита от понижения версии: открытие данных более новой версии переводит хранилище в безопасный режим read-only без перезаписи.
- **Изоляция черновиков и оптимистическая блокировка**: черновики изолированы по сессиям вкладок через `sessionStorage`. При редактировании одной заметки в нескольких вкладках версионирование по `updatedAt` предотвращает незаметное затирание изменений и предлагает выбор (перезаписать, сохранить как новую или обновить).
- **Границы параллелизма**: перед записью в `localStorage` массив заметок перечитывается для минимизации коллизий. Для обеспечения строгой межпроцессной транзакционности в высоконагруженных решениях рекомендуется использовать Web Locks API (`navigator.locks`) или IndexedDB.
